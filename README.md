# Varsha Patil - Portfolio

My personal portfolio website. The home page works like a small data report: you can filter my projects by domain (Data & BI, Web, Mobile, Machine Learning) or click a tool in the chart, and everything updates.

Live website: [paste your Vercel link here]

## What is inside
- Interactive home page with filters, a tool chart and project list
- Projects, skills, gallery, certificates, blog, resume and about pages
- Contact form that sends messages to my email (EmailJS)
- Works on phones, tablets and computers

## Built with
- React and Vite
- Framer Motion (animations)
- React Router (pages)
- D3 (skills network)
- EmailJS (contact form)
- Deployed on Vercel

## Run it on your computer
1. Download or clone this repo
2. Install packages: `npm install`
3. Copy `.env.example` to `.env` and add your own EmailJS keys
4. Start it: `npm run dev`
5. Open http://localhost:5173
